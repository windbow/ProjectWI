# ProjectWI 1차 재미 검증 보고서

검증일: 2026-08-06  
자동 재검증: 2026-08-06  
대상: 현재 Unity Editor 데이터와 전략·영지 관리·전투 수직 단면  
검증 성격: 자동 시뮬레이션, 코드·데이터 기반 플레이 흐름 분석, 기존 수동 점검 기록의 종합 평가

## 1. 결론

현재 ProjectWI는 **게임 한 바퀴가 연결되는 전략 게임 프로토타입**이며, 첫 20~40분 동안 확인할 기능과 선택지는 충분합니다. 특히 영웅을 영지 관리와 전투가 공유한다는 핵심 구조, 성 중점 사업, 원정, 실시간 전투, 사건과 목표 연결은 게임의 정체성을 만들 수 있는 좋은 기반입니다.

초기 검증에서 가장 큰 문제였던 중장기 전략 지도의 정체는 1차 보완했습니다. 장기 평화 시 ScriptableObject 설정에 따라 인접 AI 사이에 두 번째 전선이 형성되며, 전선 위협도가 중립 진영까지 적으로 계산하던 오류를 고쳤습니다. 기존 세 난이도 36개월 검사는 모두 통과해 최소 2개 AI 진영이 실제 이동합니다.

대기 전투와 사건을 해결하는 성장형·균형형·공세형 자동 플레이 정책도 추가했습니다. 후속 균형 조정에서 전략 판정의 공격자 동률 승리 불일치를 수정하고, 상호 침공 예상 전력·원정 안전 여유·공세 준비 기간을 반영했습니다. 성장형의 120개월 방어전은 206전에서 22전으로 줄었고 공세형은 120개월까지 수도 1성을 유지해 조기 전멸을 벗어났습니다.

현재 재미 완성도 추정치 **10점 만점에 5.8점**은 수동 플레이 전까지 유지합니다. 자동 검증 범위의 전황 변화는 개선됐지만, 재미 점수 자체는 사람이 긴장·후회·성취를 확인하기 전에는 올리지 않습니다.

## 2. 검증 방법과 한계

### 수행한 검증

- 표준 캠페인 120·240·480개월 장기 시뮬레이션
- 20·40·60인 전투 600스텝 성능 시뮬레이션
- 시작 수도 전투단 편성 및 첫 원정
- 적 성 도착 후 플레이어 실시간 전투 생성
- 12개월 상태 무결성
- 세 난이도 36개월 AI 운영
- 기본 전투 완주
- 캠페인 목표의 시작부터 통일까지 진행
- 시작 변형별 첫해 진행
- 현재 GameDesign의 핵심 루프와 실제 UI 동선 비교
- 성장형·균형형·공세형 자동 플레이의 24·60·120개월 진행
- 대기 사업·관계·지역·점령·영입·영웅 흔적 선택 자동 해결
- 플레이어 참가 전투의 전력 기반 자동 판정과 다음 턴 차단 해소

초기 핵심 흐름 테스트는 13건 중 10건이 통과했습니다. 당시 실패한 3건은 모두 36개월 AI 운영의 전선 이동 진영 부족이었습니다. 수정 후 해당 세 난이도 검사는 3/3 통과했고, 신규 자동 플레이·전선·공용 사건 검사는 12/12 통과했습니다.

### 한계

- 사람처럼 감정, 긴장, 성취감을 직접 느끼는 검증은 아닙니다.
- 장기 벤치마크는 플레이어가 대기 전투와 사건을 직접 해결하지 않는 무개입 조건입니다. 따라서 120개월 이후 정체는 실제 플레이의 확정 결과가 아니라, **플레이어 입력이 필요한 상태를 자동 시뮬레이션이 해소하지 못하는 문제와 실제 AI 정체가 섞인 신호**입니다.
- 아트와 음향이 임시 상태라 전투 타격감과 캐릭터 애착은 낮게 평가할 수밖에 없습니다.

## 5. 재미가 발생하는 지점

### 영웅의 기회비용

ProjectWI에서 가장 가능성이 큰 재미는 “좋은 영웅을 어디에 쓸 것인가”입니다. 아레스를 번영 사업에 남기면 성장이 빨라지고, 전투단장으로 보내면 전선이 강해집니다. 이 구조는 일반적인 시설 건설형 전략 게임보다 인물 중심 기획에 잘 맞습니다.

### 한 달 단위의 짧은 결과 회수

기본 사업과 인물 활동이 한 달에 끝나므로 선택 후 다음 턴에 결과를 확인할 수 있습니다. 목표 진행, 공훈, 관계 사건과 월간 보고가 같은 주기로 돌아오는 점은 짧은 플레이 세션에 적합합니다.

### 전략 준비와 실시간 전투의 연결

전투단 구성, 역할, 피로, 관계와 전투 결과가 캠페인으로 돌아오는 구조가 구현돼 있습니다. 자동 판정과 수동 전투의 결과 경로도 공유하므로 이후 밸런스를 다듬기 좋습니다.

## 6. 재미를 막는 핵심 문제

### 해결 — AI 전황 변화와 전선 오판

장기 평화 12개월마다 활성 전선이 설정된 최소치 2개보다 적으면, 접경 규모와 AI 성향을 평가해 인접 AI 사이에 신규 전쟁을 만듭니다. 또한 중립 접경을 적대 위협으로 계산하던 오류를 수정해 실제 전쟁 국경으로 증원·공격하도록 변경했습니다. 기존 36개월 세 난이도 검사는 3/3 통과했습니다.

### 해결 — 자동 재미 검증이 플레이어 결정을 해결하지 못함

성장형·균형형·공세형이 전투단 편성·원정, 전투, 사업·관계·지역·점령·영입·영웅 흔적 선택을 해결합니다. 정책별 24·60·120개월 지표를 반복 측정할 수 있습니다.

### P1 — 전략 방어 판정이 지나치게 강함

성장형은 전투단을 편성하지 않고 수도 1성에 머물렀는데도 120개월 동안 플레이어 참가 전투 206건을 모두 승리했습니다. 반대로 공세형은 28승 26패 이후 영토가 0이 됐습니다. 성 기본 방어력, 주둔 인물 가산과 공격 전투단 전력의 비율을 분해해 방어 전승과 공세 붕괴를 완화해야 합니다.

### P2 — 초반 군사 행동의 클릭 비용이 큼

성을 선택하고 원정을 열어 전투단이 없음을 확인한 뒤, 새 전투단을 만들고 대장·구성원·목표를 다시 지정해야 합니다. 첫 원정은 중요한 흥미 지점이므로 현재보다 한 화면에 가까워야 합니다.

### P2 — 난이도 차이를 체감하기 어려움

난이도는 AI 후보 선택 범위만 바꾸며 플레이어 자원과 규칙은 같습니다. 공정한 설계이지만 초기 후보 수가 적고 실제 12개월 결과가 같아 플레이어가 난이도 차이를 알아차리기 어렵습니다.

### P2 — 콘텐츠가 시스템 수에 비해 얇음

현재 데이터 수량은 고유 등급 100명과 일반 등급 400명으로 기계적인 인원 부족은 해소됐습니다. 다만 대량 생성 데이터의 서사·특기·관계 차별화와 실제 반복 체감은 자동 수량 검사만으로 보장할 수 없으므로 사람이 추후 검토해야 합니다.

### P2 — 전투의 승패 외 목표가 부족함

현재 전투는 역할과 명령은 있으나 제한 시간 방어, 특정 영웅 구출, 퇴로 확보, 거점 점령처럼 전장별 판단을 바꾸는 목표가 부족합니다. 병력 조합이 달라도 같은 명령 순서로 해결될 가능성이 있습니다.

3. ~~**500명 로스터와 회귀 테스트 기준 동기화**~~ — 완료  
   과거 24명 고정 수량·배치·관계·특기 기대값을 현재 데이터 정책에 맞게 갱신하고, 실제 데이터 누락과 낡은 테스트 실패를 분리합니다.

4. ~~**전략 방어·공격 전력 균형 조정**~~ — 1차 완료  
   성장형 206전 전승과 공세형 영토 0 패배의 계산 항목을 분해하고 정책별 생존·확장 목표 범위를 정합니다.

5. **첫 원정 단일 흐름화 — UI 작업 시 진행**  
   원정 창 안에서 추천 전투단 자동 편성→목표 선택→예상 전력 비교→원정을 끝낼 수 있게 합니다.

6. **영웅 배치의 손익을 즉시 비교 — UI 작업 시 진행**  
   영웅 선택 시 ‘영지 관리에 남길 때’와 ‘원정할 때’의 다음 달 예상 손익을 나란히 표시합니다.

7. **전투 목표 3종 추가**  
   섬멸 외에 방어, 구출 또는 거점 점령을 추가해 같은 전투단 구성에서도 다른 명령이 필요하게 만듭니다.

8. **초반 12턴 사건 밀도 조정**  
   중요한 사건은 2~3턴에 한 번, 일반 보고는 묶어서 표시하고 같은 유형이 연속 발생하지 않게 제한합니다.

## 8. 사용자 수동 검증에서 확인할 질문

- 첫 5분 안에 “이번 달 누구에게 무엇을 맡길지” 고민이 실제로 생기는가?
- 아레스를 영지 관리에 남기는 선택과 원정시키는 선택이 둘 다 아쉽게 느껴지는가?
- 다음 턴을 누르기 전에 기대하는 결과가 하나 이상 있는가?
- 6턴 동안 같은 사업이나 같은 버튼을 이유 없이 반복하게 되는가?
- 첫 전투까지 과정이 기대감을 키우는가, 단순한 설정 작업처럼 느껴지는가?
- 패배했을 때 전투단 구성, 명령, 영웅 상태 중 무엇이 원인이었는지 이해할 수 있는가?
- 월간 보고에서 다음 행동을 결정하는 데 필요한 소식을 10초 안에 찾을 수 있는가?

## 9. 최종 판단

현재 버전은 자동 정책에 따라 영지 관리 고수, 제한 공세, 적극 공세의 결과가 달라지며 장기 전선도 움직입니다. 먼저 500명 로스터와 기존 회귀 검사의 데이터 전제를 동기화한 뒤, 성장형의 완전 방어와 공세형의 전멸 사이 전략 전력 균형을 조정해야 합니다. 첫 원정 압축과 영웅 손익 표시는 UI 작업을 다시 시작할 때 진행합니다.

사용자 수동 플레이에서는 본 보고서의 점수보다 “첫 6턴 동안 실제로 고민한 횟수”와 “다음 결과가 궁금했던 횟수”를 기록하는 것이 가장 중요한 검증 지표입니다.
