# ProjectWI UI 시각 점검 — 2026-09-12

## 결과와 범위

Unity 6000.3.10f1의 실제 Game View와 UnityMCP로 점검했다. 수정 없이 레이아웃·이미지·가독성 이상을 기록했다. 아래 16개는 화면 수가 아니라 중복 증상을 묶은 문제 유형이다. P1은 핵심 정보 판독/조작 방해, P2는 일반 레이아웃 결함, P3는 시각적 정돈 과제다.

시나리오 선택, 전역 지도, 상단 HUD, 성 내정, 중점 사업, 인사 배치, 개인 활동, 특화 시설, 기본 시설, 위임, 원정, 성 상세, 목표, 군사, 인사, 외교, 계략, 연구, 세력, 의회, 설정, 월간 보고, 공통 메시지, 사건 선택, 첫해 안내, 다음 턴, 전투 HUD를 확인했다. 추가로 개인 활동의 행동/교류 대상, 선술집 인재실/담당자/탐색·영입, 원정의 대장/목표 선택, 실제 1월→2월 관계 사건 선택 동선을 확인했다.

기본 화면은 1920×1080 중심으로 확인했고, 추가 동선은 1366×768에서 확인했다. 월간 보고는 1366×768·1920×1080·2560×1440, 전투 HUD는 1366×768·1920×1080에서 재현했다. 모든 화면을 세 해상도에서 전수 조합 검사한 것은 아니다. 모바일 실기기, 모든 인물·사건·저장 슬롯 상태, 캠페인 승리/패배 화면은 미검증이다. 테스트 전투 종료는 시나리오 선택으로 돌아오므로 캠페인 전투 결과 화면의 검증으로 간주하지 않는다.

## 이미지 참조 검사

Assets의 meta GUID와 프리팹 Image 참조를 대조한 결과, 존재하지 않는 GUID 2종을 참조하는 위치가 20개였다. 상세 위치는 [missing-sprites.json](UIAudit/2026-09-12/missing-sprites.json)에 보존했다.

- `b4a1e2dcb5aac0544b0963ff6e9ebb02`: 19개 행정 프리팹 Header/HeaderPanel.
- `9cc490981813429449c56dc193d38cc0`: Territory의 Command-6.

모든 누락 Header가 실제 화면에서 흰색으로 보인다는 뜻은 아니다. 다른 배경을 사용하거나 해당 Image가 숨겨진 화면도 있다. 또한 이 검사는 GUID 존재 검사이며, 존재하는 GUID의 잘못된 Sprite subasset fileID까지 전수 검사하지는 않았다.

준비되지 않은 인물 초상·시설 이미지의 빈 슬롯은 프로젝트 규칙상 허용하므로 이미지 오류로 집계하지 않았다. 성 배경은 확대 시 선명도가 낮아 보이나 의도한 원화 해상도 기준이 없어 확정 결함에서 제외했다. 목표 창과 시나리오 선택은 확인한 상태에서 심한 겹침을 발견하지 않았다. 전투 배경의 중립적인 색감은 유지되어 있었다.

## 검증 기록과 주의점

- 실제 관계 사건 '함께 세운 맹세'에서 UI-02·UI-04를 확인했다. 해당 순간 UnityMCP 캡처 파일은 정상 화면이 아니어서 증거 묶음에서 제외했다. 관찰 근거는 세션의 native Unity 화면이다.
- QA 메뉴를 연속 호출하면 이전 모달 위에 다른 모달이 남을 수 있다. 이 점검 경로 때문에 생긴 모달 중첩을 일반 플레이 결함으로 보고하지 않았다.
- 일부 MCP 캡처 중 Unity PlayerLoop 재귀 호출 오류가 발생했다. 시각 결함과 원인을 연결하지 않았고, 새 테스트 전투 세션에서는 콘솔 오류가 나타나지 않았다.
- 실제 턴/편성/사건 검사는 임시 QA 캠페인에서 자동 저장을 끈 상태로 진행했다. 테스트 전투는 별도 테스트 경로를 사용했다. 마지막에 Play Mode를 종료했다.
- 게임 코드·프리팹·데이터 수정 및 테스트 추가는 하지 않았다. 보고서, 캡처와 문서의 점검 기록만 추가했다. 기존 작업 중인 변경은 유지했다.

수정 순서는 월간 보고 → 공통 Header/Sprite 참조 → 공통 카드 텍스트·초상 영역 → 개인 활동 버튼 겹침 → 전투 HUD 스킬 영역 → 나머지 제목/구분선/지도 밀집 배치를 권장한다.

## UI 점검 후 수정 (2026-09-13)

- 내정 프리팹 20개의 공통 배경·제목·안내문·초상 영역을 보정했다. 월간 보고 피벗/경계/버튼 이미지, 개인 활동 버튼과 반복 지시 겹침, 첫해 안내 장식 간섭을 수정했다.
- 전투 HUD는 미리 작성한 스킬 슬롯 4개와 페이지 버튼을 사용한다. 지도는 기존 성 이름의 배치를 화면 크기와 주변 라벨에 맞춰 보정한다. 지원 목록에서 단일 페이지의 이동 버튼을 숨긴다.
- WIUIAuditRepairUtility는 지정한 기존 프리팹 하나를 보정하며 최초 백업은 Temp/UIRepair/Backups에 둔다. 편집 모드에서 사용한다. 월간 보고 재구성에도 공통 보정이 적용된다. 미준비 이미지는 빈 슬롯으로 유지한다.
- 누락 이미지 GUID 2종의 기존 20개 참조를 정리했다. 최종 재검색 0건. UI 회귀 및 UGUI 이행 EditMode 검사 54/54 통과(job 78684effea934dfab4f018a3963a2cec), 컴파일 후 오류/경고 조회 0건.
- 수정 후 화면 증거: GameDocuments/UIAudit/2026-09-12/After. 월간 보고 1366×768·1920×1080·2560×1440, 연구, 위임, 개인 활동 목록/행동, 지도, 첫해 안내, 전투 스킬 페이지 이동을 확인했다.
- 남은 시각 검증: 최신 성 기록/중점 사업 간격 보정 재촬영, 실제 결정 카드가 채워진 월간 보고의 모든 상태, 긴 영지 이름과 검색/필터 장식의 세부 가독성. 모든 데이터 조합과 해상도에 대한 검증 완료를 뜻하지 않는다.
- 최초 점검 보고서의 '수정 없음'과 누락 참조 목록은 수정 전 기록이다. 기존 다른 작업의 변경은 유지했으며 커밋·푸시는 하지 않았다. 밸런스/마스터 데이터 구조 변경은 없다.
