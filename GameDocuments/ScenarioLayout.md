# 시나리오별 성 배치

## 아레스 메인

- 아발론은 최북단의 `프로스트혼(castle_28)` 한 곳에서 시작합니다.
- 프로스트혼은 `카르디아(castle_04)`와 연결됩니다.
- 카르디아는 발도르 소유이며 프로스트혼에서 진출할 수 있는 첫 성입니다.
- 카르디아는 점령 이후 `룬포지(castle_33)`와 `브론즈게이트(castle_34)`로 정상 진출할 수 있으며, 이 기본 연결은 내러티브 진행 여부와 무관하게 유지됩니다.
- 아이언하트 소유 성은 모두 프로스트혼보다 지도 아래쪽에 배치합니다.
- 기존 아발론 시작 성 `castle_00`은 발도르 소유로 변경하여 아발론의 시작 영토가 한 성만 남도록 합니다.
- 초기 영토는 아발론 1성, 발도르 47성, 아이언하트·실반로드·네크로폴리스 각 4성입니다.
- 발도르에는 별도의 경제·방어·증원 배율을 주지 않고 영토 수만으로 대국의 우위를 만듭니다.
- 발도르의 공격 출정 검토 주기는 24개월입니다. 다른 세력과 프리 시나리오의 기본 주기는 3개월입니다.
- 카르디아는 방어 10·질서 20의 약한 첫 관문이며 자동 공세 기준 제4개월에 점령됩니다.
- 프로스트혼은 월드맵 로컬 좌표 `(-206.88, -15.8)`에 대응하는 데이터 좌표 `(0.31342, 0.518854)`, 카르디아는 `(-199.58, -150.84)`에 대응하는 `(0.320004, 0.68)`에 배치합니다.
- 프로스트혼에는 `common_012~015`, 카르디아에는 `common_016~019` 인재 풀이 배치됩니다.

## 프리 시나리오

- 마스터 데이터의 기본 성 소유권, 좌표, 연결을 그대로 사용합니다.
- 아레스 메인 전용 배치는 프리 시나리오에 영향을 주지 않습니다.

## 월드 프리팹과 시나리오 데이터

- 월드 UI는 `WIAdministrationWorldUGUI.prefab` 하나만 사용합니다.
- 프리팹에는 60개 성 노드의 UI 구조와 참조만 저장하며, 특정 시나리오의 소유 세력이나 위치를 별도 프리팹으로 복제하지 않습니다.
- 실행 시 선택한 시나리오의 `WICampaignVariantDefinition.castlePlacements`가 성 소유 세력·좌표·연결을 결정합니다.
- 프리 시나리오는 별도 덮어쓰기 데이터가 없으므로 성 마스터 데이터의 기본 소유 세력·좌표·연결을 사용합니다.

## 데이터 편집 기준

- `WICampaignVariantDefinition.castlePlacements`는 월드에 표시되는 성의 시나리오별 소유 세력, 지도 좌표, 연결을 지정하는 데이터 테이블입니다.
- `overrideMapPosition`을 켜고 `normalizedMapPosition`의 X/Y를 0~1 범위에서 수정하면 해당 시나리오의 성 위치를 바꿀 수 있습니다. X는 좌우, Y는 상하 위치이며 Unity 화면에서는 값이 커질수록 위로 이동합니다.
- `overrideConnections`를 켜고 `adjacentCastleIds`에 연결할 성 ID를 넣습니다. 이동과 AI 경로가 양쪽에서 일관되도록 반대편 성 데이터에도 현재 성 ID를 추가합니다.
- `playerStartingCastleId`는 시작 영웅이 모일 플레이어 시작 성입니다.
- `valdorAttackIntervalMonths`는 발도르가 공격 출정을 검토하는 간격입니다.
- `recruitableHeroIds`는 해당 성에서 탐색으로 우선 발견할 수 있는 인재 목록입니다.
- 한국어 성 이름으로 요청해도 데이터베이스의 표시 이름을 통해 성 ID를 확인할 수 있습니다. 같은 이름이 중복될 때만 지역이나 세력 확인이 필요합니다.
