# ProjectWI 판타지 용어 기준

**목적:** 삼국지식 표현을 중세 판타지 영토 전략 게임의 분위기에 맞게 통일하고, UI·데이터·문서 작업에서 같은 표시 용어를 사용한다.

## 공식 표시 용어

| 이전 표현 | 공식 표현 | 사용 기준 |
|---|---|---|
| 세력 | 진영 | 국가·종족·연합을 포괄하는 상위 집단 |
| 군주 | 통치자 | 플레이어 또는 진영의 최고 지도자 |
| 내정 | 영지 관리 | 영지의 성장·시설·인물 배치 전반 |
| 태수 | 영지관 | 개별 영지의 운영 책임자 |
| 평정 | 의회 | 매월 진영 전체 방침을 결정하는 기능 |
| 월보 | 월간 보고 | 지난 턴의 수입·사건·전투 결과 보고 |
| 인사 | 영웅 / 영웅 관리 / 직책 | 메뉴는 `영웅`, 배치는 `영웅 배치`, 임명 문맥은 `직책` 사용 |
| 계략 | 첩보 | 조사·방첩·유언비어·인물 교란 기능 |
| 출정 | 원정 | 전투단이 다른 영지로 이동하거나 공격하는 행동 |
| 부대 | 전투단 | 영웅과 일반 인물이 직접 구성하는 전투 집단 |
| 등용 | 영입 | 미소속 인물을 진영에 합류시키는 행동 |
| 재야 | 방랑 | 아직 어느 진영에도 속하지 않은 상태 |
| 치안 | 질서 | 영지의 안정·범죄·반란 위험을 나타내는 수치 |
| 공적 | 공훈 | 인물이 진영과 전투에서 쌓은 기여도 |

## 성과 영지의 구분

- `성`은 도시·요새·성역 등 지도 거점의 물리적 유형이나 고유 장소를 가리킬 때 유지한다.
- `영지`는 플레이어가 관리하는 행정 단위와 관리 행위를 가리킬 때 사용한다.
- 화면 이름은 `영지 관리`, 지도 노드와 데이터 타입은 기존 `Castle` 식별자를 유지한다.

## 내부 식별자 유지 규칙

- 저장 호환성을 위해 `Faction`, `Governor`, `Scheme`, `Army`, `Recruitment`, `Stability` 등 영문 클래스·필드·열거형·ID는 변경하지 않는다.
- 플레이어에게 보이는 한국어 문구와 공식 문서만 이 기준으로 표시한다.
- 신규 고정 문구는 문자열 UID 데이터에 등록하고 코드에 한국어를 새로 하드코딩하지 않는다.
- 기존 저장 파일을 깨뜨릴 수 있는 식별자 변경은 별도 마이그레이션 작업으로 진행한다.
