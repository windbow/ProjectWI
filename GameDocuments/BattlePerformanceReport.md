# ProjectWI 전투 성능 보고서

**측정 경로:** `ProjectWI/Verification/Run Battle Performance Benchmark`  
**전투 설정:** `Assets/Data/ScriptableObject/Battle/WI_BattleConfig.asset`

## 목표

- PC 우선 기준 동시 전투 인원: 기본 20명, 권장 상한 40명, 스트레스 상한 60명
- 자동 테스트 기준: 60명·600스텝을 5초 이내 처리
- 장시간 교전 중 좌표 NaN 금지
- 남은 발사체는 인원수의 3배 미만, 시각 효과는 인원수의 2배 미만 유지

세 시나리오 모두 목표를 통과했습니다. 수치는 Unity 에디터에서 시뮬레이션 로직만 측정한 결과이며 실제 빌드의 렌더링·UI 비용은 별도 프로파일링이 필요합니다.

## 적용한 최적화

- 매 프레임 생존 인물 LINQ 목록 생성을 명시적 반복문으로 교체
- 가장 가까운 표적 탐색의 정렬·임시 객체 제거
- 발사체 충돌 후보의 LINQ 투영·정렬 제거
- 발사체 역순 순회와 인덱스 삭제로 복사 목록 제거
- 충돌 처리의 생존 인물 목록을 단일 명시적 생성으로 제한

## 남은 출시 전 검증

- Windows 개발 빌드에서 CPU·GPU 프레임 프로파일링
- 실제 초상화·이펙트 적용 후 드로우콜과 오버드로 검사
- 60명 전투 10분 연속 실행의 메모리 증가 확인
- 1920×1080과 2560×1440에서 HUD·카메라 렌더링 비용 비교
