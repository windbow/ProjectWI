# ProjectWI 내정 UI/UX 매뉴얼

## 1. UX 원칙

- 전체 대륙 조망: 60개 성과 세력 구도를 한 화면에서 확인합니다.
- 성 중심 동선: 지도에서 성을 선택한 뒤 모든 지역 행동을 처리합니다.
- 짧은 입력 경로: 모바일에서도 두세 번의 터치로 주요 행동을 완료합니다.
- 데이터 기반 표시: 성, 세력, 영웅, 시설 정보는 ScriptableObject에서 가져옵니다.

## 2. 화면 구조와 전환

게임 실행 시 PC 캠페인 시작 화면에서 여유·표준·도전 난이도를 선택합니다. 기본 선택은 표준이며 각 카드에 AI 판단 방식이 설명됩니다. 자동 저장이 없으면 `자동 저장 이어하기`는 비활성화되고, 저장이 있으면 0번 자동 저장 슬롯을 불러와 바로 전략 화면으로 진입합니다. 초기 캠페인의 플레이어 세력은 아발론으로 고정합니다.

### 공통 상단 HUD

- 연도, 월, 턴
- 플레이어 세력명
- 금화, 마나 크리스탈, 영향력과 다음 턴 예상 기본 수입
- 정보와 설정 버튼

세 자원 중 하나라도 0이 되면 상단 방침 영역에 다음 턴 기본 성 수입으로 회복할 수 있다는 안내를 표시합니다. 자원이 부족한 유료 명령은 잔액을 음수로 만들지 않고 실행되지 않습니다.

사업, 연구, 계략, 부대 편성, 부대원 추가, 선술집 의뢰와 개인 활동에서 담당 가능한 대기 인물이 없으면 공통 안내를 표시합니다. 사업·연구·활동·의뢰·이동은 다음 턴 처리 후 인물이 다시 후보로 복귀하며, 부대 소속 인물은 부대를 해산하거나 구성원에서 제외해야 다른 명령에 배정할 수 있습니다. 인물 후보가 없어도 `다음 턴`은 계속 사용할 수 있습니다.

포로 인물은 전체 인물 목록에 억류 세력과 남은 개월을 표시하고 모든 임무 후보에서 제외합니다. 질서 있는 후퇴는 중상과 포로를 막지만 즉시 패배하며, 일반 패배는 전력 차이에 따라 부상, 대패는 포로 가능성이 추가됩니다. 현재 영구 사망은 발생하지 않습니다.

전투 결과 월보에는 참가 인물별 승리·패배·질서 있는 후퇴 원인과 공적·경험·피로·부상 변화를 표시합니다. 같은 부대에서 공동 승리 기준을 채운 인물 쌍은 전우 관계 발전 소식을 별도로 표시합니다.

### 대륙 전략 화면

- 교체 가능한 대륙 지도 이미지 슬롯과 60개 성 노드
- 세력 범례, 지도 배율 및 복귀 조작
- 군사, 인사, 외교, 계략, 연구, 통치 전역 명령
- 이번 달 세력 방침을 정하는 평정과 지난 결과를 확인하는 월보
- 다음 턴 진행 버튼
- 화면 하단 안내 인물 이미지 슬롯과 전략 안내

성 노드를 선택하면 지도 위에 패널을 겹치지 않고 성 내정 화면으로 완전히 전환합니다.

`계략`에서는 조사, 방첩, 유언비어와 인재 이간의 영향력 비용·기본 성공률·기본 발각률을 확인한 뒤 담당 인물과 대상 성을 순서대로 고릅니다. 인재 이간은 마지막으로 대상 인물을 선택합니다. 출발 시 영향력을 소비하며 성공과 발각은 다음 턴에 각각 판정됩니다. 계략 화면 상단에는 진행 중인 계략, 담당 인물, 대상과 남은 개월을 표시하고 담당 인물은 결과가 나올 때까지 다른 명령 후보에서 제외됩니다. 월보에는 성공 여부, 발각 여부, 실제 성공률과 발각률을 표시하며 발각되면 대상 세력과의 외교 관계가 한 단계 악화됩니다. 조사 성공 후에는 대상 성의 네 수치와 주둔 인원, 방첩 기간을 확인할 수 있습니다.

미조사 적 성은 지도에서 `정보 미확보`로 표시하며 성 화면의 번영·기술·치안·방어, 태수 초상화, 주둔 인물과 시설을 `??` 또는 비공개 안내로 대체합니다. 조사 정보가 남아 있거나 동맹인 성만 상세 정보를 표시합니다. 플레이어 참가 미결 전투가 있으면 성 수치는 숨긴 채 전투 접촉과 전력 정보만 표시합니다.

외교 대상 화면에는 해당 세력이 억류한 아군 포로의 몸값 버튼과 양측 포로가 모두 있을 때 맞교환 버튼을 표시합니다. 동맹 관계에서는 양측이 공통으로 전쟁 중인 제3세력마다 공동 공격 제안을 표시하고, 진행 중이면 목표 성과 남은 개월을 함께 보여줍니다. 공동 공격을 받은 AI 부대는 목표 인접 아군 성으로 집결한 뒤 해당 성을 우선 공격합니다.

턴 결과와 지난달 월보에는 `AI 세력 판단 근거` 구역을 별도로 표시합니다. 각 항목은 세력과 사업·연구·군사·외교·계략 분야, 선택한 대상과 이유를 포함합니다. 연구는 선택·차순위 점수를, 군사는 전선 위협도나 공동 공격 목표를 표시하여 플레이어가 AI 행동의 원인을 추적할 수 있습니다.

난이도가 적용된 AI 판단은 월보에서 `상위 N개 중 K순위` 형식으로 표시됩니다. 이는 AI의 자원량이 아니라 판단 후보 폭의 차이이며, 같은 저장 상태와 턴에서는 같은 선택이 재현됩니다.

대륙 세력 정세 화면에서 영토가 없는 세력은 `멸망(제 N턴)`으로 표시됩니다. 멸망 세력은 외교 대상 목록에서 제외되며 최초 멸망 시점에는 턴 결과 월보에 세력 이름과 영토 상실 턴이 기록됩니다.

성 내정 화면은 PC 16:9를 우선합니다. 1366×768 이상에서는 좌측 태수 초상화, 중앙 전경·성 수치·주둔 카드, 우측 내정 명령을 한 화면에서 비교하도록 배치합니다. 주둔 인물과 특화 시설은 이미지와 이름을 분리한 카드로 표시하여 새 초상화나 아이콘 위에 글자가 겹치지 않습니다. 1365px 이하에서는 카드와 명령 패널만 축소하며 핵심 기능은 그대로 유지합니다.

### 성 내정 화면

- 교체 가능한 성 전경 이미지 슬롯
- 좌측 태수/인물 전신 이미지 슬롯
- 성 이름, 규모, 유형과 번영/기술/치안/방어 수치
- 우측 중점 사업, 인사 배치, 인재 활동, 특화 시설 선택, 기본 시설, 태수 위임, 출정, 성 상세 명령
- 하단 진행 사업, 주둔 영웅, 내정 시설 현황
- 좌측 상단 대륙 지도 복귀 버튼

성 상세에는 전문 분야 이름과 실제 효과를 함께 표시합니다. 사업 성과형 전문 분야는 해당 사업의 담당 인물 예상 성과에도 별도 가산 근거로 나타나며, 수입형과 방어형은 월간 수입 또는 전략 방어 계산에 자동 적용됩니다.

## 3. 핵심 이용 흐름

1. 대륙 화면에서 전체 세력 구도와 성 상태를 확인합니다.
2. 군사·외교·인사 등 세력 단위 행동은 하단 전역 명령에서 처리합니다.
3. 관리할 성 노드를 선택하면 해당 성 내정 화면으로 이동합니다.
4. 성 내정 명령과 슬롯 현황을 확인하고 행동을 결정합니다.
5. `대륙 지도` 버튼으로 돌아가 다른 성이나 전역 명령을 선택합니다.
6. 대륙 화면의 `다음 턴` 버튼으로 월간 연산을 실행합니다.

### 첫해 안내

첫해 1월에는 대륙 지도와 다음 턴, 2월에는 성 중심 내정, 3월에는 중점 사업, 6월에는 연구, 12월에는 군사와 첫해 점검 안내가 표시됩니다. 새 캠페인의 첫 안내는 독립 모달로, 이후 안내는 해당 월의 턴 결과 하단에 표시됩니다.

`안내 확인`은 현재 항목만 완료하고 `첫해 안내 전체 건너뛰기`는 남은 항목을 모두 끕니다. 사업을 실제 지정하거나 연구를 시작하거나 군사 메뉴를 사용했다면 대응 안내는 이미 익힌 기능으로 처리되어 반복되지 않습니다. 진행 상태와 전체 건너뛰기는 캠페인 저장에 포함되며 안내를 닫거나 건너뛰어도 다음 턴 진행은 제한되지 않습니다.

### 캠페인 결과

턴 연산이 끝난 뒤 아발론이 대륙의 60개 성을 모두 소유하면 `대륙 통일` 승리, 아발론 소유 성이 하나도 남지 않으면 `아발론 멸망` 패배가 판정됩니다. 기획에 없는 수도 단독 상실 즉시 패배는 적용하지 않습니다.

결과 모달에서는 현재 지도를 계속 살펴보거나 캠페인 시작 화면으로 돌아갈 수 있습니다. 계속 보기는 결과를 취소하지 않으며 최초 결과와 판정 턴, 확인 여부가 저장됩니다. 확인하지 않은 결과가 있는 자동 저장을 불러오면 결과 모달을 다시 표시합니다.

## 4. 모달

- 특화 시설: 성 확장 완료 후 기획에 정의된 시설 하나 선택
- 기본 시설: 성관, 시장, 훈련소와 선술집의 역할 안내
- 영웅 배치: 대기 영웅 목록
- 인재 활동: 활동 가능한 주둔 인물과 탐색/등용/교류/훈련/휴식 선택
- 인사: 영입 인물의 등급, 특기, 공적, 명성, 충성, 피로와 현재 활동 표시
- 평정: 부국, 개발, 안정, 수비, 원정, 인재 중 하나 선택
- 태수 위임: 태수, 균형/번영/연구/전선/인재 방침과 월간 예산 설정
- 월보: 자원 수입과 지출, 태수 선택 사업과 선택 이유, 완료 사업 표시
- 월보 선택 사건: 안전한 선택, 과감한 선택, 특기 기반 영웅 선택지
- 영웅의 흔적: 성당 최대 2개, 초과 시 교체 대상 선택
- 기본 시설/선술집: 월간 의뢰 확인과 주둔 담당 인물 배정
- 군사: 부대 목록, 대장 선택, 역할별 부대원 추가, 숙련과 보급 확인
- 이동/출정: 현재 성과 연결된 인접 성만 목표로 선택
- 적 성 도착 부대는 자동 점령하지 않고 전투 대기로 표시
- 부대 상세: 합동 훈련 예약, 비대장 부대원 제외와 주둔 부대 해산

중점 사업 선택 화면은 사업별 기본·집중 투자 비용을 데이터에서 읽어 표시합니다. 현재 일반 사업은 기본 100G, 집중 180G이며 확장은 기본 600G, 집중 1,080G입니다. 담당 인물 선택 단계에는 능력치·특기·세력 방침을 반영한 예상 성과를 표시합니다. 집중 투자는 더 빠른 성장을 제공하지만 금화당 효율은 기본 투자보다 조금 낮습니다.

담당 인물 버튼에는 선택 사업에 특기가 적용되는지와 특기 성과 `+2`를 별도로 표시합니다. 전체 인물 목록에서는 특기 이름만이 아니라 적용 사업과 현재 효과 설명을 함께 표시합니다. 특기 문구와 적용 사업은 ScriptableObject 데이터에서 가져옵니다.
- 점령 성: 지도에 점령 불안 표시, 성 상세에서 남은 불안 기간과 안정 조건 확인
- 출정: 3단계 다인원 부대 시스템 구현 전에는 안내만 표시
- 턴 결과: 자원 획득과 주요 소식

## 5. 이미지 교체

현재 다음 요소는 빈 이미지 슬롯입니다.

- `map-background-placeholder`: 대륙 지도
- `castle-background-placeholder`: 선택한 성의 전경
- `governor-portrait-placeholder`: 태수 또는 안내 인물 전신 이미지
- `guide-portrait`: 대륙 화면의 안내 인물

실제 에셋이 준비되면 UXML/USS의 배경 이미지 또는 컨트롤러의 Sprite/Texture 바인딩으로 교체합니다.

## 6. 반응형 기준

- 기준 해상도: 1920x1080
- 작은 화면에서는 자원 칩, 메뉴, 성 노드 폭을 축소합니다.
- 작은 화면에서는 자원 표기와 성 내정 하단 현황의 폭을 축소합니다.
- 터치 버튼은 충분한 높이를 유지합니다.
- 긴 성 이름과 영웅 이름은 줄바꿈 또는 축약 규칙을 적용합니다.

### 해상도 QA 메뉴

- `WI/QA/Game View/1366x768`, `1920x1080`, `2560x1440`에서 고정 Game View 해상도를 선택합니다.
- `WI/QA/Preview/Global Map`, `Avalon Castle`에서 전역·아발론 성 화면을 즉시 엽니다.
- `WI/QA/Preview/Long Content Global`, `Long Content Castle`에서 긴 이름과 7자리 자원 스트레스 화면을 엽니다.
- 세 해상도의 시작·전역·성 화면 비교 결과는 `GameDocuments/ResolutionQAReport.md`를 기준으로 관리합니다.

### 긴 문구와 큰 숫자

- 제한 폭의 세력·성·인물 이름은 생략 기호로 축약하고 원문을 툴팁에 보존합니다.
- 한국어 자원 값은 10,000부터 `만`, 100,000,000부터 `억` 단위를 사용합니다.
- 영문 자원 값은 1,000부터 `K`, 1,000,000부터 `M` 단위를 사용합니다.
- 자원 칩 툴팁에는 쉼표를 포함한 정확한 현재 값과 증감 값을 표시합니다.

## 7. 시각 테마

- 배경과 명령 패널: 반투명 흑색
- 주요 프레임과 일반 버튼: 차콜 및 중간 회색
- 선택·핵심 정보 카드: 백색 바탕과 검정 글자
- 일반 정보 카드: 밝은 회색 바탕과 검정 글자
- 위험 행동: 제한적인 적갈색
- 지도 성 노드와 경로: 세력 식별을 위해 기존 세력색 유지
- 금색은 기본 UI 계층에서 사용하지 않고, 향후 희귀도나 특별 보상처럼 제한된 의미에만 사용합니다.
- 장식 이미지가 없는 상태에서도 흑백 명도 대비와 테두리만으로 정보 위계가 유지되어야 합니다.

### 마우스 상호작용 상태

- 기본: 차콜 배경, 흰 글자, 회색 테두리
- 호버: 흰 배경, 검은 글자의 순간 반전
- 선택: 호버와 같은 백색 반전을 지속해 현재 선택을 표시
- 비활성: 차콜·회색 조합과 48% 불투명도로 사용 불가를 표시
- 위험: 적갈색 배경을 사용하며 진격·후퇴처럼 결과가 위험한 행동에만 적용
- `WI/QA/Preview/Interaction States`에서 다섯 상태를 한 화면으로 비교합니다.

### PC 키보드 단축키

- `M` 군사, `H` 인사, `D` 외교, `S` 계략
- `R` 연구, `G` 통치, `C` 평정, `L` 월보
- `T` 다음 턴
- `ESC`는 열린 모달을 먼저 닫고, 모달이 없다면 성 화면에서 전역 지도로 복귀합니다.
- 캠페인 시작 화면, 열린 모달, 성 화면과 텍스트 입력 중에는 전역 메뉴 단축키가 실행되지 않습니다.

### 툴팁과 계산 근거

- HUD 자원: 현재 정확한 값, 다음 턴 예상 증가량, 소유 성 수와 적용 요소를 표시합니다.
- 성 수치: 해당 수치가 자원·연구·계략·전투 중 어디에 사용되는지 표시합니다.
- 중점 사업: 기본값, 담당 적성, 투자, 특기, 전문 분야와 세력 방침을 항목별로 표시합니다.
- 연구·외교: 비용, 선행 조건, 기간과 확정 결과를 표시합니다.
- 계략: 기본 확률, 담당 지력, 대상 치안과 방첩의 가감값을 표시합니다.
- 미조사 대상은 숨겨진 치안·방첩과 최종 확률을 공개하지 않으며 조사 후 계산 근거를 제공합니다.
- `WI/QA/Preview/Calculation Tooltips`에서 대표 계산 문장을 한 화면으로 검증합니다.

### 색상 외 세력 구분

- 아발론 `[AV]`, 발도르 `[VD]`, 아이언하트 `[IH]`, 실바니아 `[SY]`, 네크로폴리스 `[NC]` 코드를 사용합니다.
- 지도 성 노드, 세력 범례, 성 상세와 노드 툴팁에 같은 코드를 표시합니다.
- 일반 이동 경로는 실선, 적대 전선은 `×`, 선택한 성의 연결 경로는 `◎`로 보조 표시합니다.
- `WI/QA/Preview/Color Vision`은 세력과 경로색을 회색으로 낮춰 코드와 형태만으로 판독 가능한지 검증합니다.

### 저장 복구

- 저장은 `.tmp`에 먼저 기록하고 자체 검증을 통과한 뒤 슬롯 파일로 원자 교체합니다.
- 기존 정상 슬롯은 같은 경로의 `.bak`에 직전 버전으로 보존합니다.
- 주 저장이 손상되면 백업을 자동 복구하고 시스템 안내 모달에 복구 사실과 원인을 표시합니다.
- 빈 파일, 잘린 JSON, 미래 버전과 필수 세력·성·인물 목록이 없는 진행 중 캠페인은 안전하게 거부합니다.
- 지원하는 구버전은 누락된 선택 컬렉션, 월·턴과 다음 번호를 기본값으로 복구합니다.

## 8. 세력 정세와 AI 경고

- 전역 `세력 정보` 메뉴는 모든 세력의 영토 수와 공개 AI 성향을 표시합니다.
- 플레이어 세력의 자원만 정확히 공개하며 적 세력의 보유 자원은 노출하지 않습니다.
- 플레이어 영토를 목표로 AI가 출정하면 지도 노드에 침공 경고 뱃지를 표시합니다.
- 점령으로 소유 세력이 바뀌면 성 노드 색상도 즉시 새 세력 색상으로 갱신합니다.
- 부대 상세 화면은 대기, 방어, 증원, 공격 중 현재 전략 임무와 목표 성을 표시합니다.
- 최근 전투 승패와 당시 부대 전투력, 재편성 남은 개월을 부대 상세 화면에 표시합니다.
- 군사 화면의 미완료 전투 세션에서 전장, 양측 세력·전력, 수비 부대 수와 플레이어 참가 여부를 확인할 수 있습니다.

## 9. 전투 HUD

### 에디터 전투 테스트 랩

Unity 상단 메뉴의 `ProjectWI/Tools/Battle Test Lab`에서 아군과 적군을 직접 편성할 수 있습니다. 데이터베이스에 등록된 `[영웅]`과 `[일반]` 인물을 양측에 중복 없이 추가하고 대장·전위·근접·원거리·마법·지원 역할을 지정한 뒤 `편성대로 전투 시작`을 누르면 MainScene 플레이 모드를 거쳐 BattleScene이 자동 실행됩니다. 테스트 승패는 캠페인 점령·보상·저장에 반영되지 않습니다.

- 상단 중앙에 전투 시간과 공격·수비 생존 인원을 표시합니다.
- 하단에 전진, 위치 사수, 집중 공격과 후퇴 명령을 큰 터치 버튼으로 배치합니다.
- 플레이어 진영 영웅의 액티브 스킬 버튼은 하단 명령 영역 반대편에 생성합니다.
- 일반 인물도 직업별 공용 액티브 스킬 버튼이 생성되며, 고유 영웅은 직업 기술 대신 전용 기술을 우선 표시합니다.
- 스킬 버튼은 영웅 고유 이름과 마나 비용을 표시하며 마나 부족·재사용 대기·전투 불능 상태에서는 이유를 버튼에 표시하고 비활성화합니다.
- 범위 피해는 적색, 아군 회복은 녹색, 지휘 강화는 금색 반투명 원으로 적용 범위를 표시합니다.
- 후퇴는 즉시 전투 패배로 처리되므로 다른 명령과 구분되는 적색 버튼을 사용합니다.
- 현재 적용 중인 명령은 금색으로 강조하고 전진·사수 효과 또는 집중 공격 대상 이름을 상단 안내에 표시합니다.
- 집중 공격은 플레이어 진영 중앙에서 가장 가까운 생존 적을 지정하며 대상 캐릭터에 금색 표적 원을 표시합니다.
- 후퇴는 첫 입력 후 3초 안에 버튼이나 R 키를 다시 눌러야 확정됩니다. 1·2·3 키는 전진·사수·집중 명령에 대응합니다.
- 플레이어가 참가하는 대기 전투는 군사 화면의 세션 상세에서 `전투 시작` 버튼으로 진입합니다.
- 전투 종료 후 전략 화면으로 돌아오면 기존 자원, 성, 부대와 월보 상태를 그대로 표시합니다.
- 실제 아트가 비어 있으면 영웅은 원형, 일반 인물은 사각형으로 표시하고 아군 적색·적군 청색, 이름·역할·체력 바를 함께 표시합니다.
- 근접 공격은 명중 지점의 원형 섬광, 원거리·마법·지원 공격은 실제 충돌 판정을 수행하는 작은 사각 발사체로 표시합니다.
- 전장 배경이 없으면 중앙선을 포함한 격자형 임시 맵과 2D 직교 카메라를 자동 구성합니다.
- PC에서는 WASD 또는 방향키로 카메라를 이동하고 마우스 휠로 확대·축소하며 Home 키로 전장 중앙 기본 시점에 복귀합니다. 카메라는 확대율과 화면 비율을 고려해 전장 경계를 벗어나지 않습니다.
- 전장의 캐릭터 가까이를 클릭하면 청록색 선택 원과 등급·이름·역할·HP·MP 정보를 좌측 상단에 표시합니다.

- 저장 데이터가 없는 슬롯은 불러오기 버튼을 비활성화합니다.
- 자동 저장 존재 여부와 턴 종료 자동 저장 사용 상태를 표시합니다.
- 불러오기 완료 후 지도 노드, HUD와 선택 성 참조를 복원된 캠페인 상태로 다시 구성합니다.

## 11. 시스템 설정

- 한국어·영어, 전체 화면, 전체·음악·효과음 음량을 시스템 모달에서 변경합니다.
- 목표 프레임은 30, 60, 120 FPS 중 선택합니다.
- `설정 적용` 시 실행 환경과 로컬 설정에 즉시 반영하고 지도 표시명을 새 언어로 갱신합니다.
- `기본값 복원`은 ScriptableObject에 정의된 기본 설정으로 되돌립니다.

## 12. 연구와 작위

- 전역 연구 메뉴는 완료 연구, 진행 중 연구와 시작 가능한 연구 목록을 표시합니다.
- 연구 버튼에는 마나 비용, 필요 기술과 기간을 함께 표시하고 다음 화면에서 유휴 담당자를 선택합니다.
- 전체 영웅 목록에서 현재 작위와 `작위 수여` 버튼을 표시합니다.
- 작위 선택지에는 필요 공적, 영향력 비용, 내정·전투 보너스를 함께 표시합니다.

## 13. 일반 인물 승격

- 전체 인물 목록은 이름 앞에 현재 유효 등급인 `[일반]` 또는 `[영웅]`을 표시하고, 클래스의 주·보조 능력치와 권장 전투 역할을 함께 보여줍니다.
- 지도에서는 모든 성을 선택해 정보 화면을 열 수 있지만, 아발론 소유 성만 `직접 관리 영지`로 표시되고 내정 명령이 활성화됩니다. 동맹·중립·적대 세력의 성은 `관찰 전용 · 세력명 소유`로 표시하며 성 상세를 제외한 사업·인사·활동·시설·태수·출정 명령을 차단합니다.
- 새 캠페인을 시작하면 아발론의 정세와 첫 목표 모달이 먼저 표시됩니다. 전역 지도 상단의 금색 목표 바는 목표명과 현재 수치를 상시 표시하며 클릭하면 조건과 보상을 다시 확인할 수 있습니다. 완료 후에는 월보에 보상 내역을 남기고 다음 목표 준비 상태로 바뀝니다.
- 목표 바는 수도 재건 이후 영토 3성, 발도르 멸망, 대륙 통일로 자동 전환됩니다. 수치형 목표는 현재값/목표값을 표시하고 각 단계의 모달에서 정세·조건·보상을 확인할 수 있습니다.
- `통치`의 대륙 세력 정세에는 각 세력의 핵심 인물 관계, 갈등·친애 단계와 배경을 표시합니다. 전체 인물 목록에서는 각 인물 옆에 연결된 상대와 현재 관계 단계를 표시합니다.
- 지역 사건이 발생하면 턴 월보에 `지역 사건` 버튼이 표시됩니다. 사건 배경과 두 선택지의 금화·마나·영향력 및 성 수치 결과를 비교할 수 있으며, 비용이 부족한 선택지는 비활성화됩니다.
- 플레이어 점령 후 월보에 `점령 통치` 버튼이 표시됩니다. 구 소유 세력과 회유·군정·현지 자치의 예상 결과 및 불안 기간을 비교합니다. 세력이 마지막 성을 잃으면 해당 세력 고유의 멸망 제목과 설명이 월보에 한 번 기록됩니다.
- 대륙 통일 승리 화면은 점령 통치 이력에 따라 `별빛 아래의 화합` 또는 `철의 왕관 아래` 제목과 결말 설명을 표시합니다. 결과 확인 후 계속 보기 또는 시작 화면 복귀가 가능하며 판정된 결말은 저장됩니다.
- 캠페인 시작 화면에서는 난이도와 별도로 정통 재건·국경 수비대·분열된 궁정 시작 조건을 선택합니다. 선택 카드는 초기 영토 또는 관계 차이를 설명하며 자원 보너스가 없다는 안내를 함께 표시합니다.
- 전투 승리 성취와 공적·명성 조건을 충족한 일반 인물에는 `영웅 승격` 버튼이 나타납니다.
- 승격 버튼에는 필요한 영향력 비용을 표시하며 확정 즉시 목록 등급과 세력 영향력을 갱신합니다.

## 13.1 관계 사건

- 같은 성에 있는 두 인물이 갈등 또는 친애 조건을 만족하면 턴 결과에 `관계 사건` 버튼이 표시됩니다.
- 사건 창은 두 인물의 이름, 상황 설명과 두 선택지를 표시합니다.
- 각 선택지 버튼에는 관계 변화와 공적·피로의 예상 결과를 선택 전에 함께 표시합니다.
- 해결한 사건은 같은 인물 조합에서 반복되지 않으며 저장·불러오기 후에도 완료 상태를 유지합니다.

## 13.2 영웅의 흔적

- 중점 사업을 대성공으로 완료하면 사업 종류에 맞는 영웅의 흔적 후보가 턴 결과에 표시됩니다.
- 흔적에는 담당 영웅, 고유 이름, 설명, 적용 사업과 성과 보너스를 표시합니다.
- 활성 슬롯 두 개가 찬 경우 새 흔적과 기존 흔적의 적용 사업·효과량을 비교하여 교체합니다.
- 교체된 흔적은 효과 없는 `기념 기록`으로 성 정보에 남아 과거 영웅의 활동을 확인할 수 있습니다.

## 13.3 등용 요구 사건

- 발견한 인재의 설득 진척이 100%에 도달하면 턴 결과에 `등용 요구` 사건이 표시됩니다.
- 사건은 기본 해결책, 공적·명성·영토를 사용하는 조건부 해결책과 교섭가 전용 해결책을 제공합니다.
- 각 버튼에 필요한 조건과 영입 후 담당자의 공적·피로 결과를 표시하며 미충족 선택지는 비활성화합니다.
- 사건을 해결하기 전까지 후보는 발견 상태로 남고 즉시 세력에 합류하지 않습니다.

## 13.4 선술집 의뢰

- 의뢰 목록에서 종류별 기간과 금화·공적·명성 예상 보상을 표시합니다.
- 담당 인물 선택 화면에는 권장 능력치와 현재 수치를 비교해 기준 이상이면 `적합`으로 표시합니다.
- 적합한 담당자는 완료 시 추가 금화를 받고, 의뢰 종류에 따라 번영·기술·안정·인재 발견·방첩 결과가 달라집니다.
- 여러 달이 걸리는 의뢰는 남은 개월을 표시하고 저장·불러오기 후에도 진행도를 유지합니다.

## 14. 인물 이동과 태수 임명

- 성의 `인재 활동` 화면에서 유휴 인물별 `인접 성 이동` 버튼을 제공합니다.
- 목적지에는 같은 세력의 인접 성만 표시하며 현재 인물 수와 슬롯 상한을 함께 표시합니다.
- 이동을 시작한 인물은 전체 인물 목록에서 목적지와 남은 기간이 표시됩니다.
- 태수 설정에서 주둔·유휴 인물을 임명하고 `태수 해임`으로 위임까지 함께 종료할 수 있습니다.
- 태수가 없는 상태에서는 위임을 활성화할 수 없습니다.

## 15. 전략 지도 연결선

- 모든 성의 `Adjacent Castle Ids` 관계를 지도 노드 사이의 연결선으로 표시합니다.
- 같은 세력의 경로는 성 소유 세력색으로 표시하고 서로 다른 세력이 맞닿은 경로는 굵은 적색 전선과 중앙 표식으로 표시합니다.
- 마지막으로 선택한 성과 직접 연결된 경로는 금색으로 강조하여 이동·출정 가능한 방향을 빠르게 확인할 수 있습니다.
- 연결선은 성 버튼보다 뒤에 배치되고 입력을 받지 않으므로 지도 선택을 방해하지 않습니다.

## 15.1 태수 위임 계획과 결과

- 위임 설정에는 현재 방침·성 수치·태수 특기를 근거로 다음 달 예상 사업, 선택 이유, 성과, 비용과 기간을 표시합니다.
- 턴 월보는 `[위임 계획]`과 `[위임 결과]`를 구분하고 예상 성과와 실제 성과를 함께 표시합니다.
- 태수 부재, 다른 임무 수행과 금화 부족으로 실행할 수 없으면 필요한 임명·대기·최소 금액을 안내합니다.

## 16. 시각 자산 표시

- 전략 지도는 `Global Map Image`에 등록된 16:9 대륙 이미지를 프레임 전체에 맞춰 표시합니다.
- 세력 문장은 상단 HUD의 세력명 옆에 표시합니다.
- 선택 성의 전경과 태수 초상화는 성 내정 화면 배경 및 좌측 인물 영역에 표시합니다.
- 주둔 인물 초상화와 특화 시설 아이콘은 하단 슬롯 배경으로 자동 표시합니다.
- 이미지가 없는 데이터는 기존 빈 슬롯과 설명 문구를 유지합니다.

## 17. 외교 메뉴

- 전역 `외교` 메뉴에서 플레이어를 제외한 4개 세력과 현재 관계를 표시합니다.
- 관계 화면은 숫자 점수 대신 현재 상태의 의미와 실행 가능한 다음 명령만 보여 줍니다.
- 전쟁에서는 휴전, 중립에서는 친선, 우호에서는 불가침, 불가침에서는 동맹을 제안할 수 있습니다.
- 동맹에서는 금화 원조를 요청할 수 있으며 남은 재요청 대기 기간을 표시합니다.
- 전쟁이 아닌 모든 관계에서 영향력을 사용해 선전포고할 수 있습니다.
