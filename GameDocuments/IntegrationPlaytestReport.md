# ProjectWI 통합 플레이 사전 점검 보고서

검증일: 2026-08-04  
대상: Windows x86-64 개발 빌드

## 자동 통합 동선

1. 표준 난이도 새 캠페인 생성
2. 월간 턴 1회 실행 및 제2턴 진입
3. 60개 성 상태 확인
4. Player 영속 경로에 저장 후 불러오기
5. 아발론 인물 아레스와 발도르 인물 리리아로 테스트 전투 진입
6. 전투 런타임과 양측 임시 도형 인물 초기화
7. 전투 시뮬레이션 1스텝 진행
8. 전투 결과 처리
9. `MainScene` 전략 UI 복귀

## 발견 및 조치

- 자동 검증이 전투 씬의 다음 프레임 초기화 전에 상태를 확인하던 순서 문제를 발견했습니다.
- 실제 게임 동선과 동일하게 비동기 씬 전환 완료를 기다린 후 전투·전략 화면을 검사하도록 스모크 테스트를 수정했습니다.
- 게임 런타임 자체의 전투 씬 누락이나 초기화 오류는 재현되지 않았습니다.
- 첫 수동 플레이에서 시작 인물은 보이지만 별도 전투단이 없어 성 화면의 원정 창이 막히는 UX 결함을 발견했습니다.
- 원정 창에서 바로 `새 전투단 편성`으로 이동하도록 연결하고 대장 선택→전투단원 추가→이동/원정 순서를 안내했습니다.
- 적 성 원정 버튼에 영향력 20 비용을 표시하고, 교전 상태·영향력·이동·전투 대기·재편성 때문에 실패할 경우 원인을 안내하도록 수정했습니다.
- 새 캠페인의 수도에서 전투단을 만들고 인접 발도르 성으로 원정할 수 있는 회귀 테스트를 추가해 EditMode 196/196을 통과했습니다.

## 남은 수동 점검

자동 검증은 기능 연결과 상태 무결성을 확인하지만 재미, 정보 밀도와 클릭 피로도는 판정하지 못합니다. 다음에는 실제 창 모드에서 30~60분 플레이하며 아래 항목을 기록합니다.

- 전역 지도에서 다음 행동을 이해하는 데 걸리는 시간
- 아발론 성 선택과 영지 관리 명령의 클릭 수
- 턴 결과 월간 보고의 우선순위와 읽기 부담
- 전투 명령과 카메라 조작의 체감
- 저장·불러오기 후 맥락 회복 난이도
