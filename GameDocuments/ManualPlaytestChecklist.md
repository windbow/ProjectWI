# ProjectWI 첫 수동 통합 플레이 체크리스트

시작일: 2026-08-04  
대상 빌드: `Builds/Windows/ProjectWI.exe`  
권장 시간: 30~60분

## 이번 플레이의 목적

기능 존재 여부는 자동 검증을 통과했습니다. 이번에는 실제 플레이 중 다음 행동을 쉽게 이해할 수 있는지, 클릭이 과도하지 않은지, 결과를 납득할 수 있는지를 확인합니다.

## 권장 진행 순서

### 1. 새 캠페인과 전역 지도 — 5분

- 표준 난이도와 기본 시작 조건으로 새 게임 시작
- 첫 목표를 닫은 뒤 현재 자원과 다음 행동 파악
- 아발론 수도와 적 성을 각각 선택
- 적 성에서는 내정 명령이 차단되고 정보만 보이는지 확인

### 2. 성 내정 — 10분

- 아발론 수도로 진입
- 번영 중점 사업을 선택하고 담당 인물 배치
- 태수 위임, 인물 목록과 성 기록을 각각 한 번 확인
- 전역 지도로 돌아가는 동선과 ESC 동작 확인

### 3. 턴 진행과 월보 — 10분

- 최소 6턴 진행
- 자원 증감과 사업 결과가 예상치와 일치하는지 확인
- 지역·관계·등용 사건이 나오면 선택 결과를 읽고 처리
- 월보에서 중요한 소식과 일반 기록이 구분되는지 확인

### 4. 군사와 전투 — 10~20분

- 군사 화면에서 아군 부대 구성과 목표 설정 확인
- 가능한 경우 인접 적 성으로 진격
- 실시간 전투 진입 후 이동·집중 공격·사수·후퇴 명령 확인
- 카메라 이동·확대와 인물 선택 정보 확인
- 전투 종료 후 전략 화면과 월보로 정상 복귀하는지 확인

### 5. 저장과 재개 — 5분

- 수동 저장 슬롯에 저장
- 시작 화면으로 돌아가거나 게임을 재실행
- 저장 슬롯을 불러와 턴·자원·사업·부대 상태 확인

## 기록 기준

| 우선순위 | 기준 |
|---|---|
| P0 | 진행 불가, 저장 손상, 크래시 |
| P1 | 핵심 명령 실패, 전투·전략 복귀 실패, 중요한 정보 누락 |
| P2 | 설명 부족, 과도한 클릭, 가독성 저하, 오해하기 쉬운 결과 |
| P3 | 문구·간격·색상 등 가벼운 개선 |

| 월보·전투 | 턴 결과 | P1 | 전투 시작 버튼이 월보 맨 아래에 섞이고 교차 침공이 두 전투로 생성됨 | 월보 본문과 고정 전투 영역 분리, 전투 전부 해결 전 턴 차단, 동일 경로 교차 침공은 한 전투 | 양측 부대를 서로의 출발 성으로 출정시킨 뒤 턴 진행 및 전투 복귀 반복 |

### 처리 완료

- 출정 창에 인물과 부대의 차이를 설명하는 문구 추가
- `이 성의 영웅으로 새 부대 편성` 버튼 추가
- 적 성 출정 영향력 비용과 실패 이유 안내 추가
- Windows 빌드 및 자동 통합 스모크 재검증 완료
- 목표 상황·설명·진행 보상에 전용 줄바꿈 스타일과 가변 높이 적용
- 긴 목표 텍스트 스타일 회귀 테스트 및 Windows 빌드 재검증 완료
- 턴 결과에 `전투 발생` 구역과 전력 표시·실시간 `전투 시작` 버튼 추가
- 모든 공통 모달 Label·Button에 `white-space: normal`, `max-width: 100%` 적용
- 플레이어 출정 도착 시 Pending 전투 생성 및 공통 모달 줄바꿈 회귀 테스트 추가
- EditMode 199/199, Windows 클린 빌드와 통합 스모크 통과
