# ProjectWI 데이터 작성 및 수정 매뉴얼
이 문서는 ProjectWI 게임 내에서 사용되는 주요 데이터(`ScriptableObject`)의 생성 및 수정 방법을 설명합니다. 모든 데이터는 Unity Editor의 Project 창에서 우클릭 메뉴를 통해 생성할 수 있습니다.

## 1. 던전 탐험 이벤트 시스템 (Dungeon Event System)

이 게임은 던전 크롤러 베이스의 방치형 게임입니다. 단순히 몬스터만 만나지 않고 "아무일 없음", "보물 상자 발견" 등 확률적 이벤트를 거치며 진행됩니다. 기획자는 이 이벤트 출현 확률과 보상을 직접 커스텀할 수 있습니다.

### 1-1. 단일 이벤트 데이터 생성 (`WIDungeonEventSO`)
하나의 텍스트 로그, 확률, 보상을 갖는 기본 단위입니다.

- **생성 방법:** `Project 창 우클릭` -> `Create` -> `WI` -> `Dungeon` -> `Dungeon Event`
- **프로퍼티 설명:**
  - **Event Type:** 이벤트의 속성입니다.
    - `None`: 아무일도 일어나지 않고 텍스트만 띄웁니다.
    - `Treasure`: 보화나 아이템을 획득합니다 (아래 Reward 항목 기입).
    - `Story`: 특수한 연출이나 텍스트를 출력합니다.
    - `Monster Encounter`: **이 이벤트가 뽑히면 즉시 턴제 전투(Battling) 페이즈로 전환됩니다.**
  - **Log Message:** 해당 이벤트가 발생했을 때 로그 패널에 띄울 텍스트입니다. (예: "축축한 냄새가 진동합니다...")
  - **Weight (중요):** 이 이벤트가 뽑힐 확률에 대한 '가중치'입니다. (1~100) 백분율이 아니며, 추후 등록할 던전의 모든 Event Weight를 합친 값 중 이 Weight가 차지하는 지분만큼의 등장 확률을 가집니다.
  - **Reward Gold / Exp:** 타입이 `Treasure` 등 보상을 지급하는 타입일 때 실제 시스템이 지급할 재화의 양입니다.

### 1-2. 던전 그룹 데이터 통합 (`WIDungeonDataSO`)
위에서 만든 여러 이벤트(EventSO)들을 하나로 묶어 "하나의 던전"으로 정의하는 데이터입니다.

- **생성 방법:** `Project 창 우클릭` -> `Create` -> `WI` -> `Dungeon` -> `Dungeon Data`
- **프로퍼티 설명:**
  - **Dungeon Id:** 시스템에서 이 던전을 식별할 고유 번호 (예: 1)
  - **Dungeon Name:** 던전의 이름 (예: "초심자의 숲")
  - **Event Pool:** 방금 전 만든 `WIDungeonEventSO` 형식의 에셋들을 드래그 앤 드롭해서 리스트에 넣어줍니다. 이곳에 들어간 이벤트들이 해당 던전 탐험 시 등장 후보로 룰렛에 올라갑니다.
# ProjectWI 데이터 작성 및 수정 매뉴얼

> [!TIP]
> **확률 세팅 예시**  
> `EventPool`에 다음과 같이 넣었다고 가정해 봅시다:  
> - "아무 일 없음" (Weight: 50)

> - "몬스터 조우" (Weight: 40)

## 2. 엑셀 연동 통합 데이터 임포터 (Universal Data Importer) 사용법

기획 효율성을 극대화하기 위해, 엑셀 문서를 복사/붙여넣기 하는 것만으로 위의 수많은 데이터 에셋(ScriptableObject)들을 단숨에 갱신/생성할 수 있는 커스텀 도구가 개발되어 있습니다. (이벤트, 몬스터, 직업 등 모두 가능합니다)

### 2-1. 데이터 작성 매뉴얼 (엑셀/구글 스프레드시트)
각 데이터 종류에 맞춰 해당하는 Column(열) 양식을 맞춰 표를 작성합니다.
순서가 반드시 지켜져야 하며, 첫 번째 줄(열 제목)은 자동으로 건너뜁니다.
> **주의:** CSV 양식이 아닌 **일반 엑셀이나 구글스프레드시트에서 영역을 드래그해서 CTRL+C(복사)한 뒤 바로 유니티에 붙여넣기(TSV 방식)** 하셔야 텍스트 내 쉼표(,) 꼬임 문제가 발생하지 않습니다.

**[타입별 양식 표기]**
#### (1) 던전 이벤트 데이터 (Dungeon Event Data)
| ID | EventType (영어) | LogMessage (보이는 텍스트) | Weight (확률가중치) | RewardGold | RewardExp |

#### (2) 직업 데이터 (Job Data)
| ID | JobName | Description | BaseHp | BaseSpeed | BaseAttack |

#### (3) 몬스터 데이터 (Monster Data)
| ID | MonsterName | MaxHp | Speed | AttackPower | RewardGold | RewardExp |

### 2-2. 유니티 적용 (가져오기) 절차
1. 작성한 엑셀(스프레드시트) 데이터를 `.csv` 형식으로 다운로드(또는 저장)합니다.
2. 다운로드한 `.csv` 파일을 유니티 프로젝트 폴더(예: `Assets/Data/`)에 드래그하여 임포트합니다.
3. 상단 메뉴에서 `WI Tools -> 통합 데이터 임포터` 를 클릭하여 툴 창을 엽니다.
4. 툴 창 드롭다운 메뉴에서 변환할 데이터의 **종류(Data Type)**를 고릅니다.
5. 아까 유니티로 가져온 `.csv` (또는 `.txt` TSV) 파일을 드래그하여 **데이터 파일 할당 칸**에 넣습니다.
6. 하단의 **[SO 에셋 생성 / 덮어쓰기]** 버튼을 클릭합니다.
7. `Assets/Resources/Data/` 하위 폴더들에 자동으로 SO 파일들이 생성되거나 덮어씌워진 것을 확인할 수 있습니다!

> [!TIP]
> **CSV 추출 기능 (Export):**
> 기존에 유니티 내부에 생성된 혹은 "통합 데이터 관리자"에서 생성/수정 된 SO 에셋들을 다시 엑셀 포맷으로 내보내려면 임포터 하단에 있는 **[SO 에셋 전체 -> CSV로 내보내기 (Export)]** 버튼을 활용하세요. 현재 선택된 탭 종류의 모든 에셋을 모아 `.csv` 파일로 바탕화면 등에 즉시 저장해 줍니다. 엑셀로 열어보거나 백업용으로 활용할 때 매우 유용합니다.

## 3. 내부 통합 데이터 관리자 (Data Manager / Table Viewer) 사용법

엑셀을 열고 임포트하는 과정조차 번거로울 때, 유니티 내부에서 인게임 밸런스를 즉시 수정할 수 있는 커스텀 표(Table) 뷰어입니다.

1. 상단 메뉴에서 `WI Tools -> 통합 데이터 관리자 (Table Viewer)` 를 클릭합니다.
2. 상단의 **[Dungeon Events], [Monster Data], [Job Data]** 탭 중 수정하려는 카테고리를 클릭합니다.
3. 내부에 등록된 모든 해당 종류의 데이터가 엑셀과 같은 열(Row/Column) 형태로 나열됩니다.
4. 유니티 플레이 도중이든 아니든, 즉시 빈칸의 숫자나 글자를 수정하면 자동으로 디스크 에셋에 저장(Dirty 셋업)됩니다! (최종 저장은 유니티 기반 저장 단축키 `Ctrl+S` 활용)
5. 새로운 행(Row)을 추가하고 싶다면 하단의 **[임시 데이터 강제 생성]** 버튼을 통해 새로운 파일을 만들 수 있습니다.  
  *(생성된 행의 가장 좌측 에셋 이름 버튼을 누르면 프로젝트 창에서 해당 파일이 포커싱되어 파일명을 쉽게 바꿀 수 있습니다.)*
